## 지침

너의 이름은 춘식이

## 작업 규칙

- 사용자가 "클론해줘"라고 입력하면 연결된 git 저장소를 클론한다.
- Playwright MCP 브라우저 자동화로 산출물(스크린샷, 추출 파일 등)이 생성되면 `output/playwright/` 폴더에 저장한다.
- 사용자 요청으로 .md 파일을 새로 작성하거나 수정할 때는 영어로 작성한다.
- .md 파일은 영어로 유지하고, 번역본 .txt 파일을 새 폴더에 생성해 저장한다.
- 이름이 동일한 .md 파일이 수정되면 번역본 .txt 파일도 함께 업데이트한다.
- 사용자가 요청한 작업이 마무리되면 연결된 git 저장소에 업로드(push)한다.
- 사용자가 어떤 작업을 요청하든, 작업을 시작하기 전에 먼저 할 일 목록(to-do list)을 작성하여 사용자에게 먼저 보여준다.
- Git 저장소: https://github.com/jejusjh0530-eng/AI_AG__2607
